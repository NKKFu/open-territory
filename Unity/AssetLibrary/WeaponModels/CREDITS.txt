ADAPTATIONS
Open Territory converts the source coordinates and scale, preserves every
source triangle, normal and UV, and separates disconnected pieces into slide,
bolt, magazine and body groups for the existing animations. Pistol and pulse
reload inserts add 24 triangles each to the static source models. The pulse
emitter adds a turquoise emission material. The art is baked into shared Unity
mesh/material assets and local Resources prefabs; no network access or runtime
geometry generation is used by the player.

Reproduce prepared data: python Unity/Tools/prepare-weapon-models.py
Rebuild prefabs in Unity: Open Territory > Import free weapon models
Prepared source/geometry hashes: prepared-manifest.json
Downloaded file hashes: download-manifest.json
